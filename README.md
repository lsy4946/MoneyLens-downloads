## 설치

1. Android 휴대전화에서 위 APK 다운로드 링크를 엽니다.
2. 내려받은 APK를 열고, Android가 요청하면 해당 브라우저나 파일 앱에 대해 ‘이 출처의 앱 설치 허용’을 설정합니다.
3. 머니렌즈를 설치하고 실행합니다. **Android 8.0 이상**과 최신 Android System WebView/Chrome이 필요합니다.
4. 기존 머니렌즈가 있다면 삭제하지 않고 업데이트 설치합니다. 앱 삭제·데이터 초기화 시 보관함이 지워집니다.
